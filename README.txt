DruryIT Codex Handoff

Contents:
- current_code/ : current DruryIT Support V1 bundle
- CODEX_SHORT_PROMPT.txt : concise deployment prompt for Codex

Recommended workflow:
1. Extract this ZIP into a new Codex project folder.
2. Open that folder in Codex.
3. Paste CODEX_SHORT_PROMPT.txt into Codex.
4. Let Codex inspect the current_code folder before making changes.

Codex does not automatically see files from this ChatGPT conversation unless those files are present in the folder/workspace Codex is operating on.
